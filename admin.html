🗄️ Base de données à configurer

  1. Crée un projet gratuit sur supabase.com (région Europe).
  2. SQL Editor : exécute supabase/1-schema.sql, puis supabase/2-seed.sql.
  3. Authentication → Users → Add user (ton e-mail + un mot de passe), puis exécute supabase/3-admin.sql avec ton e-mail.
  4. Project Settings → API Keys : copie la Publishable key (sb_publishable_…) dans js/config.js, avec l'URL https://<Project ID>.supabase.co. ⛔ Jamais une Secret key.
  5. Recharge cette page.

Tous les détails : README, section « 🗄️ Base de données ».

📥 Ajouter plusieurs questions d'un coup

        
Une question par ligne, colonnes séparées par |. Tu peux aussi copier-coller des lignes depuis Excel ou Google Sheets, ou choisir un fichier CSV :

        
question | bonne réponse | mauvaise réponse 1 | mauvaise réponse 2 | anecdote 💡 (optionnel) | réponses acceptées à l'écrit, séparées par ; (optionnel)

        
Thème « questions libres » 💕 : uniquement la question. Les doublons (même question, même bonne réponse) sont détectés et ignorés.
